# npm 2.0.0 release report

## Status

Prepared and verified on 2026-08-22, merged and published on 2026-08-23. The npm registry serves `2.0.0` from the `latest` tag.

## Version decision

This release moves from `1.7.0` to `2.0.0`. It is a major release because it raises the minimum Node.js version from 18 to 20, replaces the legacy MCP SDK and session lifecycle with MCP 2026-07-28 stateless calls, rejects legacy clients, and changes the tool catalog.

`package.json` is the authoritative version source. Webpack injects that version into the production MCP server, and the live verifier confirms that `server/discover` advertises the same value.

## Package contents

`npm pack --dry-run --json` produced a 75,239-byte package with 26 files and a 361,724-byte unpacked size. It contains the production bundle, source map, declarations, README, license, and package manifest. It excludes source files, tests, examples, local configuration, and development tools.

## Verification

- TypeScript 7 typecheck passed.
- ESLint and architecture boundaries passed with zero warnings.
- Prettier passed.
- Vitest passed 52 tests across 8 files.
- The production build passed.
- The live MCP verifier passed and reported version `2.0.0`.
- A clean `npm ci` completed and ran the TypeScript 7 production build.
- All 410 resolved lockfile packages passed the seven-day maturity gate.
- `npm audit` reported zero vulnerabilities.
- Independent standards review found no unresolved hard or medium issues.

The first PR run exposed `electron-to-chromium@1.5.412`, published inside safe-chain's seven-day waiting period. The direct-only maturity check had not inspected that transitive resolution. The package now pins seven compatible transitive families to their newest mature releases and checks the complete lockfile, preventing safe-chain from discovering young packages one failure at a time.
